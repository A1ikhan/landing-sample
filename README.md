# Тише — презентационный лендинг стоматологии

Вымышленная клиника, демонстрационные цены, специалисты, отзывы и контакты. Форма записи проверяет поля и показывает подтверждение; данные не отправляются и не сохраняются.

## Разработка

Node.js 24 и npm 11 (использованы при проверке).

```sh
npm ci --cache /workspace/.npm-cache
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

```sh
npm run build
npm run lint
```

`build` включает проверку TypeScript. Статическая сборка находится в `dist/`.

Для проверки сборки: `npm run preview -- --host 0.0.0.0 --port 4173 --strictPort`.

## Настройка для клиента

Контент и моковые данные: `src/data.ts`. Компоненты: `src/App.tsx`. Дизайн и адаптивность: `src/App.css`.

Иллюстрации сделаны средствами CSS: внешние шрифты, изображения и API не требуются. Для реального сайта необходимо заменить демонстрационные данные, подключить обработку заявок и подготовить политику обработки персональных данных.
